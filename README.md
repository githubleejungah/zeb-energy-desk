# 제로에너지 단지 운영 데스크 (시제품)

> 상태: 시제품 완성 · 로컬 확인(2026-11-24). 아직 공개하지 않음.

가상의 제로에너지(ZEB) 아파트 단지 하나를 네 사람이 각자 화면으로 봅니다.

| 화면 | 누가 | 하는 일 |
|---|---|---|
| 시공사 콘솔 | 태양광 · 신재생 설비 시공사 | 설치 확인, 손실 큰 순서의 알람, 출동 묶기, 하자 · 보증, 의무 사후관리 보고서 |
| 입주민 앱 | 입주민 · 설비 소유주 | 발전량 · 사용량, 고장 알림, 발전 중 사용 미션과 포인트 |
| 단지 화면 | 건설사 · 관리주체 | 단지 현황, 제휴 리워드 |
| 본사 운영 어드민 | 서비스 회사 운영자 | 구독 요금 정산, 장애 보상, 예외 대기열 |

- 데이터는 모두 가상입니다. 실제 회사 · 고객 · 가격이 아닙니다.
- 에너지 ICT 회사의 서비스 기획자 지원용 개인 프로젝트입니다. 문서 초안 · 코드는 Claude(AI)와 함께 만들었습니다.

## 실행법

빌드가 없습니다. `site/` 폴더를 정적 서버로 엽니다.

```
python -m http.server 8794 -d site
```

브라우저에서 `http://localhost:8794`를 엽니다. 위쪽 버튼으로 역할을 바꾸고, '1시간 · 1일 앞으로'로 시각을 넘깁니다.

시험(Node 22 이상):

```
node tools/run-tests.mjs      # 결과: tmp/test-results.json
node tools/secret_scan.mjs .  # 비밀값 검사
```

## 시연 순서(5분)

1. **시공사:** 안전 알람이 맨 위, 그다음 손실 큰 순. 통신이 끊긴 곳은 '추정'. 지도에서 출동 묶음 확인.
2. **본사 운영자:** 월 정산 '마감'이 잠겨 있음(남은 일 9건). 예외 6건 판정(담당 없는 PV-32는 '이관 결정' 3갈래 중 하나), 본사 대기열 담당 지정.
   - **건설사 · 관리주체:** 공용 설비 알람의 현장 1차 확인(체크리스트 → 해결 / 안 됨). 안전 알람은 '전문가만'.
   - **시공사:** 손실이 작은 알람은 '보류' — 14일 또는 보류 뒤 손실 3만 원이면 본사로.
3. **1시간 앞으로 × 4 → 시공사:** 안전 알람 '조치 입력' → **1일 앞으로** → 다음 날 정상 복귀로 종결.
4. **본사 운영자:** 새로 올라온 48시간 미확정 건 처리 → 마감 → 감면 확정이 감사 기록에.
5. **1일 앞으로 × 7:** 감사 기록에 '원본 삭제'(15분 원본). 입주민 판정 결과는 그대로.
6. **입주민 · 관리주체:** 1시간 합계만, 단지 합계만, 제휴사엔 5가지 합계만.
