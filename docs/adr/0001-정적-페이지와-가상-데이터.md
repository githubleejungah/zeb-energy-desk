# ADR 0001 — 정적 페이지와 가상 데이터

- 상태: 채택 · 2026-11-24 (요구 Q8 사용자 승인)
- 근거: 이전 시제품들과 같은 방식, 지원 일정

## 결정

GitHub Pages 정적 페이지로 만든다. 가상 단지 하나의 데이터를 파일로 넣고, 화면에서 바꾼 상태는 보는 사람 브라우저에만 둔다. 서버 · 외부 API는 쓰지 않는다.

## 이유

- 심사자가 링크를 열 때마다 같은 시연이 나와야 한다.
- 요금 · 키 관리 · 개인정보 전송 위험이 없다.
- 지원 일정(2026-11-28 제출 목표) 안에 안정적으로 끝낼 수 있다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 작은 서버 + DB | 배포 · 비용 · 일정 부담, 시연 가치가 크지 않음 |
| 화면 설계서(그림)만 | 정산 · 예외 규칙이 실제로 도는지 보여 줄 수 없음 |

## 결과

- 정산 · 예외 규칙은 순수 함수로 만들어 시험한다. 입사 후 회사 서버로 옮길 때 입력 · 출력 모양을 유지한다.
- 숫자는 가상이라 성과가 아니다. 화면과 문서에 그렇게 적는다.
