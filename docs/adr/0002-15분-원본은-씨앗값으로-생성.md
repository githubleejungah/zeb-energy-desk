# ADR 0002 — 15분 원본은 저장하지 않고 씨앗값으로 만든다

- 상태: 채택 · 2026-11-24 (설계 승인 · 구현 완료)
- 근거: requirements Q6 · Q8 · Q9, AC-46 · AC-47 · AC-33

## 결정

세대 사용량 15분 원본은 브라우저에 저장하지 않는다. `raw.js`가 '세대 id + 날짜'를 씨앗값으로 그때그때 만든다(같은 입력이면 같은 값). 이 함수는 정산 모듈만 불러 쓴다.

## 이유

- 300세대 × 96칸 × 31일 ≈ 89만 개 값은 브라우저 저장소(보통 약 5MB)에 넣기 어렵다.
- 저장하지 않으면 원본이 화면 · 저장소 · 내보내기로 새는 길이 처음부터 없다.
- 심사자가 열 때마다 같은 시연 결과가 나온다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 원본을 JSON 파일로 올림 | 파일이 커지고, 공개 파일이라 누구나 원본을 내려받음(시연이라도 나쁜 본보기) |
| 1시간 단위만 만듦 | 사용자 결정(Q6: 15분 수집)과 판정 불가 사례(15분 빈 칸)를 보여 줄 수 없음 |

## 결과

- '원본 삭제'는 그 달을 생성 금지 목록에 넣는 방식으로 흉내 낸다(AC-47).
- 마감 계산이 3초를 넘으면 세대 묶음별로 나눠 계산한다.
