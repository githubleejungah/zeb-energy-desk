# ADR 0003 — 역할 나누기는 화면에 넘기기 전 필터로 만들고, 시연임을 밝힌다

- 상태: 채택 · 2026-11-24 (설계 승인 · 구현 완료)
- 근거: requirements Q1 · Q8 · 1-3, AC-02 · AC-05

## 결정

역할 × 칸 노출표를 `views.js` 한곳에 두고, 화면은 필터를 거친 데이터만 받는다. 정적 페이지라 진짜 보안이 아니므로 화면 · 문서에 "시연이며 실제 제품은 서버가 권한을 검사"라고 적는다.

## 이유

- 화면마다 숨기기(CSS로 감추기)를 하면 데이터는 그대로 남아 새기 쉽다. 넘기기 전에 거르면 시험으로 '금지 칸 0개'를 증명할 수 있다.
- 입사 후 서버로 옮길 때 같은 노출표를 서버 권한 검사로 옮기면 된다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 실제 로그인 · 서버 | 비용 · 일정(Q8) |
| 화면에서만 감추기 | 데이터가 화면 쪽에 남아 금지 칸 0개를 증명할 수 없음 |

## 결과

- 잔여 위험 R-1(개발자 도구로 가상 데이터 보기)은 받아들이고 밝힌다.
