# ADR 0004 — 지도는 외부 지도 대신 가상 동네 배치도(SVG)로 그린다

- 상태: 채택 · 2026-11-24 (설계 승인 · 구현 완료)
- 근거: requirements Q11 · A11(시안 승인), AC-20 · AC-48

## 결정

출동 지도는 외부 지도 서비스를 쓰지 않고, 기준 데이터의 배치도 좌표로 SVG를 그린다. "실제 지도 아님"을 표시한다.

## 이유

- 외부 지도는 열 때마다 외부 서버 요청이 생겨 '외부 전송 0건'(AC-48)과 부딪힌다.
- 지도 키 · 약관 · 비용 문제가 없다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 국내 · 해외 지도 서비스 | 외부 요청 · 키 관리 · 약관 |
| 지도 빼기 | 사용자가 시안을 보고 넣기로 결정 |

## 결과

- 입사 후 회사 지도 서비스 연결은 로드맵 2번.
