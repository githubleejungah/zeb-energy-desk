# ADR 0006 — 알람은 저장하지 않고 계측 + 사람 행동으로 매번 계산한다

- 상태: 채택 · 2026-11-24 (구현 중 결정, 설계 승인 범위 안)
- 근거: requirements Q4 · A4, AC-06~18, flows F1

## 결정

알람 · 작업 지시는 저장하지 않는다. 설비 계측(1시간)과 사람 행동 기록(출동 확정 · 조치 결과)을 시간 순서로 다시 훑어 매번 계산한다. 저장하는 것은 사람 행동뿐이다.

## 이유

- '1일 앞으로'처럼 시각이 바뀌어도 48시간 · 7일 규칙이 항상 같은 답을 낸다.
- 저장된 알람 상태와 규칙이 어긋나는 일이 없다(정본은 계측과 행동 기록 하나).
- 시험이 쉽다: 같은 입력이면 같은 결과.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 알람을 저장하고 시각이 바뀔 때마다 갱신 | 갱신을 빠뜨리면 상태가 어긋나고, 되돌리기 · 초기화가 복잡함 |

## 결과

- 계산은 설비 40곳 × 시연 기간 시간 수만큼 돈다. 화면 계산 약 0.1초(측정).
- 실제 제품은 계측이 쌓이므로 '마지막 계산 시점 이후만' 계산하는 방식으로 바꾼다(입사 후).
- 미션 판정은 반대로 기록한다(원본 삭제 뒤에도 판정이 바뀌면 안 되므로, data-model 1절).
